# Module Rules

## Tools
Primary discovery: TAAFT, Creati.ai. Target: best ~1,000. Score using configured weights. Reject dead, duplicate, unverifiable and low-value tools.

## Companies
AI must be central to the product/business. Prioritize AI-native and strongly AI-focused companies. Initial major target: ~8,000.

## Agents
Primary discovery: Creati.ai Agents. Must be genuinely agentic, functional and active. Do not classify basic generators/chatbots as agents.

## MCP
Primary discovery: Creati.ai MCP Servers/Clients. Verify using official registry/GitHub/documentation. Target ~10,000 excellent MCPs, never at the expense of quality.

## Robots
Primary discovery: TAAFT Robots and Robot Observatory. Distinguish concept/prototype/research/pilot/commercial/deployed. Initial ceiling ~1,000.

## Devices
Primary discovery: TAAFT Devices and Physical AI Devices. AI must be meaningful functionality. Initial ceiling ~1,000.

## Models
Primary discovery: TAAFT Models and Models.dev. Collapse serving/provider/quantization variants when they represent the same underlying model. Initial target ~2,000.

## News
Build an automated source → crawl → extract → clean → normalize → deduplicate → event-group → rank → publish pipeline. Target 20–30 high-quality stories/day, not maximum article volume.
