# Acceptance Criteria

A record can be automatically curated only when:

1. The entity/product exists.
2. The official source is accessible or an authoritative alternative is documented.
3. The core identity is verified.
4. The record is not a duplicate.
5. Required module-specific fields are sufficiently evidenced.
6. The record clears the module's quality threshold.
7. Provenance and verification timestamps are stored.
8. No unsupported values were invented.

For news:
- article/event must be recent enough for the ingestion window;
- event duplicates must be clustered;
- source credibility and event impact must be evaluated;
- the daily selection must be limited to the configured 20–30 range.

For all modules:
**quality threshold is a ceiling/target, never a quota that justifies lowering standards.**
